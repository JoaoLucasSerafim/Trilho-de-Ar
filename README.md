# Trilho-de-Ar
Experimento de Física sobre movimento retilíneo uniforme em um trilho de ar, com um carrinho. O objetivo desse projeto é criar um site que faça a conta com os inputs do usuário, e retorne um arquivo do excel com as contas feitas, e se possível, gráficos
